Notes:
Controlled SOC Home Lab test.

A dedicated Windows local account was created for this scenario.

Multiple invalid password attempts were intentionally generated
against the account SOC-LAB-LOCKOUT.

Wazuh first identified password guessing behavior through
Rule 100140.

After the Windows account lockout threshold was reached,
Windows generated Event ID 4740.

The native Wazuh Rule 60115 detected the account lockout,
and the custom Rule 100155 correlated the lockout with the
previous password guessing activity against the same account.

The final alert was generated at Level 13 and mapped to:

T1110.001 - Password Guessing
T1531     - Account Access Removal

In a production environment, this scenario would require
investigation to determine whether the lockout resulted from:

- malicious password guessing;
- user error;
- stale credentials;
- scheduled tasks or services;
- compromised systems;
- automated attack activity.

The analyst should review authentication history, source hosts,
affected accounts, related endpoint activity, and any subsequent
successful authentication attempts.

No malicious activity was identified because this was an
authorized and controlled laboratory test.

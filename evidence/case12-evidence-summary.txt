TELEMETRY COVERAGE FINDING
WIN10 Internet traffic uses NAT source 10.0.2.3.
Zeek/Suricata passive monitoring is attached to the Host-Only sensor path.
Therefore, some Internet-bound NAT traffic may not be visible to passive network sensors.
Sysmon Event IDs 3 and 22 provide compensating endpoint-side network/DNS visibility.

FALSE-MATCH LESSONS
1. IOC strings in analyst grep commands can become searchable SIEM telemetry.
2. Presence of WMIC alone is not evidence of malicious discovery; command line and parent context matter.
3. PowerShell Script Block Logging can capture the analyst's own hunting regex.
4. Time-based hunt cutoffs help separate pre-existing activity from investigation-generated telemetry.

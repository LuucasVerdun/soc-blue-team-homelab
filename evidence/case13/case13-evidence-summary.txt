ANALYST VALIDATION
------------------
Native Wazuh rule 92657 described the earlier NTLM network logon as possible pass-the-hash and possible RDP. The actual context was authorized SMB/445, Logon Type 3, NTLM V2. Do not classify the case as Pass-the-Hash or RDP from that alert description.

LIMITATIONS
-----------
1. Long-lived SMB session reused across tests.
2. No fresh 4624 in final run.
3. Sysmon Event 1 did not populate ParentImage.
4. PID 612 -> services.exe was validated later, not recorded in Event 1.
5. Suricata signature is supporting evidence, not standalone proof.
6. Final-run WIN10 source-file hash was not independently retained in the supplied output.
7. Authorized controlled simulation, not a real compromise.
